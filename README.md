## Featured projects

### [MERCHALI for MOD](https://github.com/alizaghrioui/merchali-for-mod)

A Chrome extension that turns a design reference into controlled variations and detailed English image-generation prompts.

- Load Amazon ASINs or capture a product image from supported marketplaces.
- Choose **Change Artwork**, **Change Text** or **Change Both**.
- Set art style, niche, composition, occasion and custom Rules independently.
- Review editable design analysis, save reusable presets and export batch prompts.
- Connect your own Gemini, OpenAI or Anthropic Claude API key.

[View source & installation guide →](https://github.com/alizaghrioui/merchali-for-mod#install-the-chrome-extension)

### [Amazon Merch on Demand SEO Listing Generator](https://github.com/alizaghrioui/amazon-merch-on-demand-seo-listing-generator)

A Chrome extension for artwork analysis and design-specific listing preparation: titles, feature bullets, descriptions, keyword planning and preliminary policy checks.
